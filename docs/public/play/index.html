Grand Theft Auto in your browser

OpenGTA runs here as opengta.wasm on the gasm runtime: the same module as on the desktop, a port of the original game's code, reading the maps, graphics, sounds and music from your own copy of GTA. Nothing from the game is on this site, and nothing you pick leaves your computer.

OpenGTA is early: the menus work and a mission starts, but walking, driving and the missions aren't ported yet. See Status.

What you need

  • Grand Theft Auto for Windows from Rockstar's 2002 re-release: the folder you installed it to (with GTADATA and WINO), or the unzipped GTAINSTALLER.zip (with data1.cab and data2.cab). See Game data.
  • A browser with WebAssembly and Web Workers: a recent Chrome, Edge, Firefox or Safari. No WebGPU needed.
  • About 330 MB of browser storage to import the data (once; later visits start at once), or none to play without importing.
  • A keyboard.

Or choose the game again below to replace it.

The installed game (for example C:\Program Files\Rockstar Games\GTA, with GTADATA, WINO and Music), or the folder you unzipped GTAINSTALLER.zip into: the game is read straight from the installer's cabinets, no installation needed.

    Importing copies the files the game reads into this site's private browser storage (OPFS). Playing without importing reads them from the folder you picked, which you'll need to pick again next time.

    Resolution and skins

    2x to 4x draw the city again at that resolution with OpenGTA's hires renderer (an addition, not part of the original game; the game itself plays the same). It costs speed: 2x keeps up on most computers, 3x and 4x often don't. The line under the game shows the frames per second: a mission runs at 70.

    Skins

      No skins added.

      A skin is a folder of your own replacement images (with a skin.ini) for tiles, sprites, fonts and pictures; whatever it doesn't have is drawn from the original art. Where several skins that are on have the same image, the one higher in the list wins. Skins are kept in this browser like the game data, and work at every resolution. To make one, see Create a skin.

      Controls

      The game reads the keyboard directly, with the original's keys. More in Controls.

      KeyIn the menus
      Up / DownChoose an entry, a mission
      Left / RightChange a setting, the player, the city
      EnterSelect, start the mission
      Esc (tap)Back; on the start menu: the credits, then quit
      Del / RPlayer select: rename / reset the player
      SpaceThe level's cutscene, once seen

      Holding Esc for a second stops the game. In fullscreen the browser takes Esc to leave fullscreen. Player names, scores and options are kept in this browser.
